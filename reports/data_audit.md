# Data audit

This aggregate report is generated by `scripts/prepare_data.py` from transcript-only FLEURS TSVs at the pinned dataset revision. It contains no original sentence text.

- Source: [Google FLEURS](https://huggingface.co/datasets/google/fleurs), Amharic `am_et` and English `en_us`.
- License declared upstream: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Revision: `70bb2e84b976b7e960aa89f1c648e09c59f894dd`.
- Raw audio is never downloaded.
- Raw TSVs and aligned sentences stay local and are excluded from version control and model releases.
- Sentence IDs are joined across the two language configs; repeated recordings are reduced to one transcript per ID; conflicting transcript IDs are excluded.
- Cross-split sentence-ID and exact-text leakage checks are run before model training.

Run `uv run python scripts/prepare_data.py` to regenerate `reports/data_audit.json` and the split counts.
